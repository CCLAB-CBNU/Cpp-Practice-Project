## 여러 파일 조합: [코드 4-10] ~ [코드 4-12]

세 코드는 하나의 프로그램을 헤더 파일, 구현 파일, 메인 파일로 나눈 것입니다. 아래 이름으로 한 폴더(또는 한 프로젝트)에 저장한 뒤 함께 빌드합니다.

| 저장할 파일 이름 | 넣을 코드 |
|---|---|
| `mathutils.h` | [[코드 4-10]](%EC%BD%94%EB%93%9C_4-10.h) |
| `mathutils.cpp` | [[코드 4-11]](%EC%BD%94%EB%93%9C_4-11.cpp) |
| `main.cpp` | [[코드 4-12]](%EC%BD%94%EB%93%9C_4-12.cpp) |

```bash
g++ -std=c++17 mathutils.cpp main.cpp -o mathutils
```

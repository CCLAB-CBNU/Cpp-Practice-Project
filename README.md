## 파일 이름 규칙

- 책의 [코드 N-M]은 `코드_N-M.cpp` 파일에 들어 있습니다. 예: [코드 14-8] → `Chapter14/코드_14-8.cpp`
- 제목이 헤더 파일인 코드는 `코드_N-M.h`로 저장했습니다. 예: [코드 14-1] → `Chapter14/코드_14-1.h`
- 파일 내용은 책의 코드와 같습니다. 단, [코드 14-15]와 [코드 14-17]에는 편향(bias) 갱신 코드가 추가되어 있습니다([Chapter14/README.md](Chapter14/README.md) 참고).

## 빌드 방법

코드 하나가 프로그램 하나인 경우에는 해당 파일만 컴파일합니다.

```bash
g++ -std=c++17 코드_2-2.cpp -o run
```

- 본문(1~14장)은 C++17, 부록 A는 C++20 이상으로 컴파일합니다.
- Visual Studio에서는 새 프로젝트를 만들고 코드를 `.cpp` 파일에 붙여 넣어 실행합니다. C++ 표준은 프로젝트 속성 > C/C++ > 언어 > C++ 언어 표준에서 바꿉니다.
- 파일은 UTF-8로 저장되어 있습니다. Visual Studio에서 내려받은 파일을 그대로 열었을 때 한글 출력이 깨지면, 파일을 "서명 있는 UTF-8"(BOM 있는 UTF-8)로 다시 저장하세요.
